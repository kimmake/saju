# 이미지 에셋 출처

| 파일 | 출처 | 권리 |
|---|---|---|
| `pine.webp` | 김홍도(1745–1806?), 「송하취생도(松下吹笙圖)」 윗부분 소나무 (Wikimedia Commons: *Kim Hong-do, Songhachwisaengdo.jpg*) | 퍼블릭 도메인 |
| `plum.webp` | 어몽룡(1566–?), 「월매도(月梅圖)」 매화 가지 부분 (Wikimedia Commons: *어몽룡 월매도.jpg*) | 퍼블릭 도메인 |
| `landscape-mist.webp`, `landscape-peaks.webp` | 정선(1676–1759), 「인왕제색도(仁王霽色圖)」 부분, 화제·낙관 제외 (Wikimedia Commons: *Inwangjesaekdo.jpg*) | 퍼블릭 도메인 |
| `hanji*.webp`, `mountains-*.webp`, `moon-panorama.webp`, `enso.webp` | `scripts/art/hanji.py`, `landscape.py`로 직접 렌더링 | 자체 제작 |
| `sun.webp`, `lantern.webp`, `books-brush.webp`, `seal-texture.png`, `zodiac/*.webp` | `scripts/art/illust.py`, `zodiac.py`로 직접 렌더링한 담채 삽화 | 자체 제작 |
| `corner.svg`, `cloud.svg` | 전통 회문·구름문을 단순화해 직접 그린 벡터 | 자체 제작 |

퍼블릭 도메인 그림은 `scripts/art/extract.py`로 오래된 종이 색을 걷어 내고 먹만 남겨 투명 배경으로 만들었다(글씨·낙관이 있는 부분은 잘라 냄).
원본은 Wikimedia Commons 표준 크기 썸네일(1920px)을 내려받아 썼다.
